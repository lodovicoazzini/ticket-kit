Ticket Kit

Options. Changes save as you type and sync with your browser profile.

Placeholders

Click one to insert it into the field you edited last. Values are from a sample ticket.

Default copy

What the shortcut and a click on the toolbar icon copy.

The link always points to the ticket URL. Rich editors like Teams, Outlook and Confluence show this text.

Pasted where only plain text is accepted, such as a commit dialog or a terminal.

Extra formats

Right-click the toolbar icon to copy in one of these. Both copy plain text only.

Brackets in the values are escaped, the URL is left as is.

Branch names

"Copy branch name" builds prefix/KEY-short-summary. The prefix depends on the issue type. In the action menu you can always pick one of the other prefixes too.

One rule per line, like Bug = bugfix or Task = chore. Type names are matched without regard to case. Leave the prefix empty for no prefix.

Leave it empty for branch names without a prefix.

Jira site

Filled in the first time you use Ticket Kit on a Jira tab. Used where there is no Jira tab to go by: "Open in Jira" on selected text, the j keyword in the address bar, and ticket search in the menu.

Shortcuts

The browser manages extension shortcuts on its own page. In Dia, set each one's scope to Global there, and pick combinations no other app uses.
